Exercise 7.14 – Transforms

Thuộc tính transform xoay, nghiêng, dịch chuyển và phóng to/thu nhỏ phần tử mà không làm thay đổi document flow.

Gốc
không transform
Rotate
rotate(15deg)
Skew
skew(-20deg, 0)
Translate
translate(30px, 20px)
Scale
scale(1.3)
Kết hợp
rotate + scale + translate

Ứng dụng: thẻ sản phẩm nghiêng nhẹ, ảnh phóng to khi hover
