## 2. Mục tiêu

Hoàn thành đủ 03 bài Lab và xây dựng trang chủ giới thiệu:

1. **Lab 08 – JavaScript 1: Language Foundations**: cú pháp, biến, hàm, mảng, đối tượng, Console.
2. **Lab 09 – JavaScript 2: DOM and Events**: truy xuất/sửa DOM, xử lý sự kiện, biểu mẫu, gỡ lỗi.
3. **Lab 10 – JavaScript 3: jQuery**: bộ chọn, sự kiện, DOM, hiệu ứng, GET request và jqXHR.

## 4. Mô tả ngắn từng Lab

**Lab 08** (12 mục): 8.1–8.5 nhúng JavaScript (embedded, external, noscript, Console); 8.6 đối tượng có sẵn (String, Date, Math); 8.7 mảng và bảng lịch tháng; 8.8–8.9 hàm, phạm vi biến, hàm như đối tượng; 8.10–8.11 đối tượng và mảng đối tượng; 8.12 là bài mở rộng đi kèm bộ Lab (dựng trang du lịch bằng hàm).

**Lab 09** (8 mục): 9.1 chọn phần tử DOM; 9.2 quan hệ cha–con–anh em; 9.3 tạo/xóa phần tử; 9.4 xử lý sự kiện click/mouseover/mouseout; 9.5 sự kiện load; 9.6 gỡ lỗi sự kiện; 9.7 focus/blur trên biểu mẫu; 9.8 kiểm tra dữ liệu biểu mẫu.

**Lab 10** (10 mục): 10.1 cài đặt jQuery (CDN + dự phòng); 10.2–10.3 bộ chọn; 10.4 sự kiện; 10.5 chèn phần tử; 10.6–10.8 hiệu ứng và hoạt ảnh; 10.9 GET request; 10.10 jqXHR (done/fail/always).

> Exercise 10.9 và 10.10 gọi dịch vụ web `randyconnolly.com`. Nếu dịch vụ này không phản hồi, mã sẽ tự dùng dữ liệu dự phòng `Lab10/data/cities.json`.
